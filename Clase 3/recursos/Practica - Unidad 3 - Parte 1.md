Unidad 3 - Alcance, Tiempo y Recursos

Caso “Implementación de una página Web para E-Commerce”

Una empresa mediana de artículos deportivos.
Actualmente vende únicamente en sucursales físicas.
La Dirección decide lanzar un canal de ventas online para llegar a todo el país antes de la campaña navideña. Faltan 7 meses para navidad.
El Director Comercial considera que se trata de un proyecto relativamente simple:
"Solo necesitamos una página web para vender productos."
El Directorio aprueba el proyecto con un plazo de seis meses.
El Director de Sistemas es designado Project Manager.

Alcance aprobado por el Directorio
Los requerimientos aprobados son únicamente:
Catálogo de productos. 
Carrito de compras. 
Pago con tarjeta. 
Registro de clientes. 
Gestión de pedidos. 
Panel administrativo.

Objetivo
Aplicar los conceptos de alcance, EDT (WBS), cronograma, dependencias y asignación de recursos para analizar el impacto que producen los cambios de alcance sobre la planificación de un proyecto tecnológico.

Actividades a realizar
Analizar el proyecto aprobado.
Identificar objetivo, alcance y principales entregables.
Construir un EDT de hasta tres niveles.
Definir las principales dependencias entre actividades.
Elaborar un cronograma simplificado identificando el camino crítico.
Asignar perfiles profesionales a cada grupo de actividades justificando la asignación.
